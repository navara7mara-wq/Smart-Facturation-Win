# Tableau de bord — Pixel Perfect v3

Cette version conserve le canevas visuel approuvé **1672 × 941 px**.

## Correction principale

Sur les écrans larges (à partir de 1750 px), le tableau de bord est maintenant mis à l’échelle comme une seule interface. Le menu latéral, les cartes, les textes, les graphiques, les tableaux et les espacements gardent donc les mêmes proportions que l’image de référence.

## Vérification recommandée

1. Lancer l’application avec `python app.py`.
2. Ouvrir `http://127.0.0.1:8000/`.
3. Garder le zoom du navigateur à **100 %**.
4. Appuyer sur **F11** pour masquer les barres du navigateur lors de la comparaison plein écran.

En mode fenêtré, une petite barre de défilement verticale peut apparaître sur un écran 1920 × 1080, car les barres du navigateur réduisent la hauteur disponible.
